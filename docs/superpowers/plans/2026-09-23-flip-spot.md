# Flip Spots and Spot Entry Rules Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let arrows pass back over themselves, apply the owner's pass-through, reverse and bend entry rules to every directional spot, and ship magenta flip spots that reverse once an arrow has fully passed, introduced in authored level 30 and generated from level 31 without ever making a level unwinnable.

**Architecture:** Spot direction becomes game state (`GameState.spotHeadings`), read by one state-aware lookup that already yields all three entry rules. Movement tracks body cells leaving flip spots to fire flips mid-move and records them in `MoveResult.spotFlips`; a collision keeps the starting spot state. On flip levels every parked single arrow stores exact cells in `settledPaths`. Flip spots appear only inside small seeded cores that are isolated from every other arrow's routes and proven stranding-free by exhaustive enumeration, so the rest of the level keeps its reverse-construction certificate.

**Tech Stack:** TypeScript, Bun test runner, three.js, Vite, Biome, Playwright headed browser tests.

**Spec:** `docs/superpowers/specs/2026-09-23-flip-spot-design.md`

## Global Constraints

- Arrows never collide with themselves. Only other arrows block.
- Entry rules for every spot, static or flip: a head travelling the spot's direction passes through; one travelling opposite reverses and travels back the way it came; one from either side bends onto the spot's direction.
- A flip spot reverses (north ↔ south, east ↔ west) at the moment no cell of the passing arrow remains on it. One passage, one flip. Static spots never change.
- A collision leaves every spot at its direction from the start of the move: a spot the arrow never cleared stays put; a spot it cleared flips back; a pending flip on a parked arrow stays pending; the rebound flips nothing.
- No collision-free move may ever make a level unwinnable. Only collisions cost lives.
- Hints stay free and unlimited until V1.
- Flip glyph: a filled dot followed by one chevron, `flip: 0xc0266d` light, `0xff6fb5` dark.
- Level 30 is authored (`FLIP_INTRO_LEVEL`, seed `par-arrows:runtime:7:level:30:flip-intro:1`); generated flip cores start at level 31; `flipCoreFrequency(id)` is 0 below 31, 0.25 at 31 rising linearly to 0.50 at 70, then holding.
- `GENERATOR_VERSION` stays 7. `CONTENT_VERSION` becomes 12.
- Every generated level without a flip core keeps the layout it has after Task 1 (Task 1 is the only task allowed to change non-flip layouts).
- Preview sessions (`?feature=flip` included) never write campaign saves.
- Each task touches at most five source files plus tests, ends with its focused tests green and `make checkall` green, and is committed atomically. No registry publishing.

## Review Focus

1. **Collision while the tail is still on a flip spot.** The spot must not flip and must not "flip back". Task 3 pins it with a unit test where the arrow bends through a spot, collides two cells later with its tail still on the spot.
2. **A reversing arrow re-entering the spot it is still on.** It must flip the spot exactly once, when its last cell finally leaves. Task 3 pins it with the level-30 reverser trace.
3. **Reload between a park-on-spot and the move off it.** The pending flip must fire on the next move after reload, with no extra saved field. Task 5 pins it by saving a state with an arrow parked on a flip spot, reloading, and moving it.
4. **A hint shown after a flip.** Hints and pick preference must use the current spot state, never the authored heading. Task 9 pins it headed: after the level-30 reverser leaves, the hint must not point at the runner, which the flipped spot now turns into the guard. Task 3 pins the same state in core (`runner` is `blocked` by `guard` after the reverse).
5. **Existing levels whose arrows reversed into themselves were previously rejected.** Removing self-collision must not produce a level that can loop forever. Task 1 pins it with a validation test that a two-spot ping-pong layout is rejected with a loop error, and Task 8 re-checks generated levels 31–90 and the byte-identical baseline for 2–120.

```ts
import { cellKey, oppositeHeading } from "./topology";
import type { Cell, Heading, LevelDefinition } from "./types";

type SpotSource = Pick<LevelDefinition, "directionals">;

interface SpotIndex {
  readonly headings: ReadonlyMap<string, Heading>;
  readonly flips: ReadonlySet<string>;
}

const SPOT_INDEX = new WeakMap<SpotSource, SpotIndex>();

function index(level: SpotSource): SpotIndex {
  let cached = SPOT_INDEX.get(level);
  if (!cached) {
    const spots = level.directionals ?? [];
    cached = {
      headings: new Map(spots.map((spot) => [cellKey(spot.cell), spot.heading])),
      flips: new Set(
        spots.filter((spot) => spot.kind === "flip").map((spot) => cellKey(spot.cell)),
      ),
    };
    SPOT_INDEX.set(level, cached);
  }
  return cached;
}

/**
 * The heading a spot sends any entering head along, or undefined when the
 * cell carries no spot. A flip spot reads its current direction from
 * `spotHeadings`; levels are immutable, so the per-level index is cached.
 */
export function spotHeadingAt(
  level: SpotSource,
  cell: Cell,
  spotHeadings?: Readonly<Record<string, Heading>>,
): Heading | undefined {
  const key = cellKey(cell);
  const { headings, flips } = index(level);
  if (flips.has(key) && spotHeadings?.[key]) return spotHeadings[key];
  return headings.get(key);
}

export function isFlipSpot(level: SpotSource, cell: Cell): boolean {
  return index(level).flips.has(cellKey(cell));
}

export function hasFlipSpots(level: SpotSource): boolean {
  return index(level).flips.size > 0;
}

export const flippedHeading = oppositeHeading;
```

```ts
/**
 * True when some collision-free reachable state has an arrow whose tap is
 * safe with the flip spots as they are and a collision with them reversed,
 * or the other way round. Undefined when the state space exceeds `limit`.
 */
export function flipInterest(
  level: LevelDefinition,
  limit = 5000,
): boolean | undefined {
  const flips = (level.directionals ?? []).filter((spot) => spot.kind === "flip");
  if (flips.length === 0) return false;
  const seen = new Set<string>();
  const pending = [createGameState(level)];
  const safe = (kind: string): boolean => kind === "exit" || kind === "paused";
  while (pending.length > 0) {
    const state = pending.pop() as GameState;
    const key = solveKey(state);
    if (seen.has(key)) continue;
    if (seen.size >= limit) return undefined;
    seen.add(key);
    for (const arrowId of state.remainingIds) {
      for (const target of targetsFor(level, arrowId)) {
        const result = simulateState(level, state, target.arrowId, target.endpoint);
        for (const spot of flips) {
          const spotKey = cellKey(spot.cell);
          const current = spotHeadingAt(level, spot.cell, state.spotHeadings) as Heading;
          const reversed: GameState = {
            ...state,
            spotHeadings: { ...(state.spotHeadings ?? {}), [spotKey]: oppositeHeading(current) },
          };
          const other = simulateState(level, reversed, target.arrowId, target.endpoint);
          if (
            safe(result.kind) !== safe(other.kind) &&
            (result.kind === "blocked" || other.kind === "blocked")
          ) {
            return true;
          }
        }
        if (!safe(result.kind)) continue;
        const next = applyMove(level, state, result);
        if (next !== state) pending.push(next);
      }
    }
  }
  return false;
}
```

```ts
function sha1Hex(text: string): string {
  const bytes = new TextEncoder().encode(text);
  const words: number[] = [];
  for (let index = 0; index < bytes.length; index += 1) {
    words[index >> 2] = (words[index >> 2] ?? 0) | ((bytes[index] as number) << (24 - (index % 4) * 8));
  }
  const bitLength = bytes.length * 8;
  words[bitLength >> 5] = (words[bitLength >> 5] ?? 0) | (0x80 << (24 - (bitLength % 32)));
  words[(((bitLength + 64) >> 9) << 4) + 15] = bitLength;
  let [a, b, c, d, e] = [0x67452301, 0xefcdab89, 0x98badcfe, 0x10325476, 0xc3d2e1f0];
  const w = new Array<number>(80);
  for (let block = 0; block < words.length; block += 16) {
    for (let t = 0; t < 80; t += 1) {
      w[t] =
        t < 16
          ? (words[block + t] ?? 0) | 0
          : (() => {
              const x = (w[t - 3] as number) ^ (w[t - 8] as number) ^ (w[t - 14] as number) ^ (w[t - 16] as number);
              return (x << 1) | (x >>> 31);
            })();
    }
    let [aa, bb, cc, dd, ee] = [a, b, c, d, e];
    for (let t = 0; t < 80; t += 1) {
      const [f, k] =
        t < 20 ? [(bb & cc) | (~bb & dd), 0x5a827999]
        : t < 40 ? [bb ^ cc ^ dd, 0x6ed9eba1]
        : t < 60 ? [(bb & cc) | (bb & dd) | (cc & dd), 0x8f1bbcdc]
        : [bb ^ cc ^ dd, 0xca62c1d6];
      const temp = (((aa << 5) | (aa >>> 27)) + f + ee + k + (w[t] as number)) | 0;
      ee = dd;
      dd = cc;
      cc = (bb << 30) | (bb >>> 2);
      bb = aa;
      aa = temp;
    }
    a = (a + aa) | 0; b = (b + bb) | 0; c = (c + cc) | 0; d = (d + dd) | 0; e = (e + ee) | 0;
  }
  return [a, b, c, d, e].map((word) => (word >>> 0).toString(16).padStart(8, "0")).join("");
}
```

```ts
interface FlipCore {
  readonly arrows: readonly ArrowDefinition[];
  readonly spot: DirectionalSpotDefinition;
  /** Every cell any core arrow can reach under either spot direction. */
  readonly footprint: ReadonlySet<string>;
}

function flipCore(
  id: number,
  level: LevelDefinition,
  occupied: ReadonlySet<string>,
  restart: number,
): FlipCore | undefined {
  if (coreStream(id, "flip-plan", 0).next() >= flipCoreFrequency(id)) return undefined;
  const rng = coreStream(id, "flip-core", restart);
  const pattern = FLIP_PATTERNS[rng.int(FLIP_PATTERNS.length)] as (typeof FLIP_PATTERNS)[number];
  const faces = shuffledFaces(rng);
  for (let attempt = 0; attempt < 64; attempt += 1) {
    const face = faces[attempt % faces.length] as FaceId;
    const rotation = rng.int(4);
    const base: Cell = {
      face,
      x: 1 + rng.int(Math.max(1, level.gridSize - 6)),
      y: 1 + rng.int(Math.max(1, level.gridSize - 6)),
    };
    const at = ([dx, dy]: readonly [number, number]) => patternCell(base, dx, dy, rotation);
    const spot: DirectionalSpotDefinition = {
      cell: at([2, 2]),
      heading: rotateHeading(pattern.heading, rotation),
      kind: "flip",
    };
    const arrows: ArrowDefinition[] = pattern.arrows.map((entry) => ({
      id: `r${id}-flip-${pattern.name}-${entry.name}`,
      path: entry.cells.map(at),
    }));
    const cells = [...arrows.flatMap((arrow) => arrow.path), spot.cell];
    if (
      cells.some(
        (cell) =>
          cell.x < 0 || cell.y < 0 || cell.x >= level.gridSize || cell.y >= level.gridSize ||
          occupied.has(cellKey(cell)),
      )
    )
      continue;
    const coreLevel: LevelDefinition = { ...level, arrows, directionals: [spot], stops: [] };
    if (!validateLevel(coreLevel).valid) continue;
    if (hasStrandingState(coreLevel) !== false) continue;
    if (flipInterest(coreLevel) !== true) continue;
    const footprint = new Set<string>();
    for (const heading of [spot.heading, oppositeHeading(spot.heading)]) {
      const probe: LevelDefinition = { ...coreLevel, directionals: [{ ...spot, heading, kind: "static" }] };
      for (const arrow of arrows) {
        for (const cell of arrowTrack(probe, arrow)) footprint.add(cellKey(cell));
      }
    }
    if ([...footprint].some((key) => occupied.has(key))) continue;
    return { arrows, spot, footprint };
  }
  return undefined;
}
```
