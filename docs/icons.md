# Par Arrows icon suite

The suite uses the game's cube, flat arrow, ink, ice, and blue visual language. Browser favicons use a simplified mark that stays readable at small sizes; installation icons retain the fuller cube design.

## Outputs

| Use | Files |
| --- | --- |
| Browser icon | `public/favicon.ico`, `public/favicon.svg` |
| Raster favicons | `public/favicon-16x16.png`, `favicon-32x32.png`, `favicon-48x48.png`, `favicon-64x64.png`, `favicon-128x128.png` |
| Apple home screen | `public/apple-touch-icon.png` (180 × 180) |
| Standard PWA | `public/icon-192.png`, `public/icon-512.png`, `public/icon.svg` |
| Maskable PWA | `public/icon-maskable-192.png`, `public/icon-maskable-512.png` |

## Regenerate and verify

Run `make icons` from the repository root to regenerate the checked-in files. Edit the original artwork in `assets/icons/app-icon.svg`, `assets/icons/favicon.svg`, and `assets/icons/maskable-icon.svg`. The generator is `scripts/generate-icons.ts`; it uses the project's pinned Sharp dependency and requires no external design tools.

Run `make checkall` and `make browser-test` to validate the asset and metadata contract. The full gate includes `make icons-check`, which checks generated bytes without writing files and rejects missing or stale exports. While the development server is running, open `/docs/icon-preview.html` to inspect native-size favicons, light/dark tab previews, the Apple icon, and device-mask crops.

Maskable foreground artwork is kept inside the centered safe-zone circle with radius 40% of the image size. Maskable and Apple images have opaque backgrounds. The manifest declares standard and maskable purposes separately. See the [W3C safe-zone specification](https://www.w3.org/TR/appmanifest/#icon-masks) and [MDN icon metadata reference](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Manifest/Reference/icons).

Preview crops demonstrate artwork clearance; physical OS installation and saved-state behavior remain separate qualification work.

## Verification record

On 2026-09-14, two consecutive regeneration runs produced byte-identical outputs. Editing a source SVG without regenerating correctly failed the freshness check and left public assets untouched. The full project gate passed with 43 tests and 806 assertions. Headed Chrome and WebKit production checks verified the manifest, icon URLs, and content types alongside the gameplay suite. Unit checks decode the PNG and ICO frames, verify dimensions and opaque Apple/maskable backgrounds, and compare HTML/manifest metadata with the asset inventory.

Native-size favicons, light/dark tabs, and device-mask crops were inspected in the [saved preview](verification/icon-suite.png). The cube and arrows fit within the maskable safe-zone overlay.
